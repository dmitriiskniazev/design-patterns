# Context
Курс статический, данные и полные исходники встроены в course-data.js. Вход web/index.html использует относительные пути.

# Decisions
Собирать .build/site с прежней структурой и корневым переходом в web/. Service worker в корне сайта кеширует локальные файлы при установке. Версия кеша определяется содержимым сборки; новая версия активируется после закрытия прежних окон, без смешивания ресурсов. Не кешировать внешние ссылки. Позицию хранить локально; явная ссылка имеет приоритет. Иконки PNG генерируются стандартной библиотекой.

# Risks
iOS может удалить кеш при нехватке места. Установка и фактическое поведение на iPhone требуют проверки на устройстве. GitHub-репозиторий пока не найден; публикация зависит от доступа.
