## ADDED Requirements

### Requirement: Публикация статического курса
Сборка MUST работать под префиксом репозитория GitHub Pages без серверной части.

#### Scenario: Адрес проекта
- **WHEN** читатель открывает корень опубликованного проекта
- **THEN** открывается курс с рабочими локальными ресурсами и ссылками

### Requirement: Чтение без сети
После успешной загрузки офлайн-копии курс MUST открывать все темы, код и локальные комплекты без сети. Интерфейс MUST сообщать о готовности офлайн-копии только после успешной установки кеша.

#### Scenario: Офлайн
- **WHEN** после сообщения о готовности отключена сеть и страница перезагружена
- **THEN** темы и полные реализации остаются доступны

### Requirement: Возврат к чтению
Курс MUST сохранять раздел и позицию на устройстве; явная ссылка MUST иметь приоритет. Ошибка хранилища MUST NOT мешать чтению.

#### Scenario: Повторное открытие
- **WHEN** курс открыт без указанного раздела
- **THEN** восстанавливаются сохранённые раздел и позиция

### Requirement: Установка на главный экран
Курс MUST предоставлять имя, иконки и автономное окно для установки в iOS.

#### Scenario: Узкий экран
- **WHEN** курс открыт на телефоне
- **THEN** навигация доступна касанием и клавиатурой, а длинный код прокручивается внутри блока
