## Context

До изменений попытка открыть эталон через CUA завершилась `Browser is not available: iab`; инвентарь вернул `apps: [], browsers: []`. Скриншоты и вычисленные стили получить нельзя. Текст страницы прочитан через веб-инструмент.

## Reference observations

| Параметр | Наблюдение | Ограничение |
| --- | --- | --- |
| Структура | Поиск, навигация, заголовок страницы, разделы с подзаголовками | Только текстовое представление |
| Разделители | Между крупными разделами присутствуют горизонтальные разделители | Толщина и цвет не измерены |
| Ширина, шрифты, отступы, код | Не измерены | Браузер недоступен |

Источник: https://docs.ag-ui.com/introduction. Значения CSS ниже — проектные решения, а не измерения эталона. Нельзя заявлять визуальное соответствие.

## Goals / Non-Goals

Цель: удобная страница Adapter с общей оболочкой документации. Сохранить короткие фрагменты, переключение файлов, офлайн-подсветку и существующие маршруты. Не менять содержание курса и не добавлять зависимости интерфейса.

## Decisions

- Макет: каталог 16rem, материал до 44rem, оглавление 12rem; переменные для изменения всех ширин.
- Шкала отступов: .25/.5/.75/1/1.5/2/3rem. Основной текст 1rem/1.7, код .8125rem/1.7; системные sans-serif и monospace.
- Ниже 1200px оглавление сворачивается над материалом; ниже 960px каталог становится выдвижным.
- Теория читается в одну колонку; рамки оставлены у интерактивных схем, кода и примечаний.
- Оглавление строится из текущих заголовков и резюме блоков. Ссылка сохраняет тему, раздел, шаг и целевую секцию.
- Каталог закрывается Escape, возвращает фокус; скрытый фон недоступен клавиатуре.

## Risks / Trade-offs

Без браузера нельзя проверить переносы, фактический контраст, клавиатуру и размеры 390/768/1440 в обеих темах. Проверки структуры и логики не заменяют визуальную приемку; изменение остаётся активным до неё.
