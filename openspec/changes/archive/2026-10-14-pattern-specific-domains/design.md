# Design

## Context
Курс уже содержит 25 тем и сборщик фрагментов по AST. Старые доменные сценарии закреплены в нескольких требованиях learning-interface.

## Goals / Non-Goals
**Goals:** разные узнаваемые задачи; небольшой код; соответствие теории, примеров, проверок и скачиваемых комплектов.
**Non-Goals:** новые категории, зависимости и переделка навигации.

## Decisions
- Каждая тема получает самостоятельную модель и одну возможность в расширении. Общая доставка больше не является ограничением.
- Модели, механизм паттерна и запуск остаются раздельными файлами. Сравнения до паттерна показывают реальное место роста веток или повторения кода.
- Источники паттернов и ссылки на темы сохраняются. Сгенерированные файлы обновляются сборщиком.
- Проверяются свойства паттернов, ограничения модели и автономный запуск 50 комплектов. Объяснения называют подключения, контракты и тесты, которые всё равно надо менять.

## Risks / Trade-offs
- Неполная замена терминов → проверка активных материалов на старую предметную область.
- Случайная потеря свойства паттерна → тесты поведения и ревью кода по пяти осям.
- Удаление авторских исходников → резервная копия /private/tmp/design-patterns-before-domain-change.

| State | Управлять музыкальным проигрывателем |

| Observer | Следить за температурой станции |
| Command | Редактировать текст с отменой |
| Chain of Responsibility | Проверить заявку на вход в игровую комнату |
| Iterator | Обходить музыкальный плейлист |
| Mediator | Обмениваться сообщениями в комнате чата |
| Memento | Восстановить рисунок из снимка |
| Visitor | Обрабатывать дерево арифметического выражения |
| Interpreter | Собрать фильтр учебных заметок |
| Factory Method | Создать экспорт учебной заметки |
| Abstract Factory | Собрать интерфейс в одной теме |
| Builder | Собрать игрового персонажа |
| Prototype | Клонировать шаблон монстра |
| Singleton | Выдавать номера отладочных событий |
| Adapter | Воспроизвести звук через чужой SDK |
| Bridge | Рисовать фигуры разными движками |

| Decorator | Наложить эффекты на звук |
| Facade | Подготовить запись подкаста |
| Flyweight | Разделить стили деревьев в лесу |
| Proxy | Загружать игровые ресурсы по запросу |
| Repository | Хранить карточки для повторения |
| Dependency Injection | Проверять будильник без ожидания |
