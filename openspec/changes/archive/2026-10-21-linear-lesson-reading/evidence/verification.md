# Проверка последовательного чтения

Дата: 2026-10-21.

## Обнаруженные причины

- Четыре равноправные вкладки, отдельные кнопки всех шагов и переходы из схемы конкурировали между собой.
- В теории схема показывалась до простого решения и новых требований; список ролей и первый листинг дублировали другие блоки.
- Схема и вложенный просмотр файлов повторялись на каждом шаге.
- Каталог переносил раздел старой темы в новую.
- Последний расширенный шаг возвращал к практике, создавая петлю.

## Изменённое поведение

Для каждой из 25 тем действует цепочка: постановка и мотивация → базовые шаги → самостоятельное задание → расширенные шаги → начало следующей темы. Прогресс и соседние переходы вычисляются из одной последовательности. После последней темы показано завершение курса.

Теория идёт одной колонкой; схема следует после идеи. Переходы из схемы, вкладки, список шагов и предварительный листинг удалены. На промежуточных шагах нет повторной схемы или полного комплекта. В конце каждого разбора доступны команда, ZIP и раскрываемое последовательное чтение файлов. Python-примеры не изменялись.
