## ADDED Requirements

### Requirement: Понятные имена учебных файлов
Все25 тем MUST использовать имена предметных модулей, раскрывающие их содержимое и обязанность. Файлы расширений MUST NOT называться extra.py. Точки запуска MUST называться main.py и run_extended.py; исходные решения MUST называться without_pattern.py и without_pattern_extended.py. Переименование MUST обновлять импорты, команды, подписи и ссылки на исходники; прежние имена в ссылках полной реализации MUST открывать соответствующий переименованный файл.

#### Scenario: Чтение состава примера
- **WHEN** читатель выбирает файл полной реализации любой темы
- **THEN** его имя описывает предметное содержимое либо однозначно обозначает запуск или вариант без паттерна

#### Scenario: Прежнее имя
- **WHEN** ссылка полной реализации содержит прежнее имя переименованного файла
- **THEN** открывается тот же файл под актуальным именем

## MODIFIED Requirements

### Requirement: Связи полного исходника
Область полного кода MUST объяснять назначение файла и предоставлять переходы к его импортируемым локальным файлам выбранной версии. При смене режима MUST выбираться существующие файлы каждой стороны; исходный файл without_pattern.py MUST заменяться файлом расширения without_pattern_extended.py, если он был выбран по умолчанию. Некорректные значения URL MUST NOT приводить к пустому экрану. Список и код MUST помещаться в ширину страницы, допуская локальную прокрутку.

#### Scenario: Чтение Strategy
- **WHEN** пользователь открывает полную реализацию с паттерном
- **THEN** сначала видит main.py и может перейти в enemy_factory.py, затем Enemy и movement_protocol.py, не раскрывая список всех исходников

#### Scenario: Восстановление ссылки
- **WHEN** открывается ссылка на версию и файл
- **THEN** выделен соответствующий файл и показан его точный исходник; отсутствующий файл заменяется входным

### Requirement: Точные наборы сравнения
Все25 тем MUST предоставлять четыре явно различимых набора: базовый без паттерна, базовый с паттерном, расширенный без паттерна и расширенный с паттерном. Наборы исходного решения MUST включать транзитивные локальные зависимости и MUST NOT смешивать посторонние файлы другого режима. Реестр общих исходников MUST оставаться дедуплицированным.

#### Scenario: Расширение Decorator
- **WHEN** выбран режим расширения
- **THEN** слева доступен without_pattern_extended.py и его without_pattern.py, справа — run_extended.py и обработка ClipLimit из audio_limiter.py

#### Scenario: Общий файл
- **WHEN** обе стороны выбрали одинаковый исходник
- **THEN** виден один полный текст с указанием его общности, а выбор файлов обеих сторон остаётся доступен
