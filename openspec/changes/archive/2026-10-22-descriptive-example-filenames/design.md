## Context
Названия файлов видны в сравнениях и служат навигацией по архитектуре. Одинаковое extra.py скрывает совершенно разные расширения.

## Decisions
Именовать предметные модули по содержимому; не усложнять уже понятные имена enemy.py, history.py или playlist.py. Общие имена оставить только для точек запуска и версий без паттерна. Точку запуска сборщик получает из entryFile; режим архива определяется явно. Словарь прежних имен находится в guide-метаданных соответствующей темы и используется при восстановлении URL.

## Validation
Пересборка всех25 тем; полная проверка инфраструктуры и каждой темы; независимый запуск версий сравнения; проверки реального HTML-рендера и старых имен в URL. Проверка браузером зависит от доступности браузерной поверхности.
