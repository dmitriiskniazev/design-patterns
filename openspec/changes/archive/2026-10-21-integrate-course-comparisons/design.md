## Context

Текущий app.js рендерит отдельный шаг. Во временном макете уже проверены четыре варианта каждой из четырёх тем: без паттерна, с паттерном и их расширения. Перенос HTML из /private/tmp без исходников сделал бы курс зависимым от временных файлов.

## Goals / Non-Goals

Перенести согласованный формат в основной курс, сохранив самостоятельный запуск каждого файла и честное сравнение. Не переписывать остальные 21 тему в этой ограниченной работе.

## Decisions

- Добавить comparison-метаданные в существующие темы. Данные содержат пути файлов, имя в собираемом примере, точку запуска и ожидаемый вывод.
- Базовые реализации паттернов используют существующие исходники. Независимые исходные решения хранятся в before/, изменённые файлы — в before_extended/. Для каждой из четырёх тем нужны отдельные compare_extended.py, сохраняющие одинаковые сценарии обеих сторон.
- При сборке прочитать и подсветить полные файлы. Проверки собирают каждую версию во временной папке, запускают отдельным процессом и сравнивают вывод; расширения накладываются на соответствующую базу.
- Рендерить две колонки с полными файлами без скачивания. На узком экране колонки располагаются последовательно, а код прокручивается внутри своего блока.
- Ссылки прежних разделов четырёх тем открывают соответствующую смысловую часть одной страницы. Для остальных тем остаётся существующий маршрут шагов.
- Убрать ссылки на скачивание и из старого интерфейса; комплект файлов остаётся читаемым на странице. Генерацию исторических ZIP не менять в этой работе.
- Версии URL CSS/JS в web/index.html изменяются вместе с внедрением, чтобы основной вход загрузил новые данные и renderer.

## Risks / Trade-offs

Полные файлы длиннее коротких листингов — это явный запрос пользователя. Дублируемые небольшие модели исходных версий нужны для независимого запуска каждой колонки. Визуальная проверка зависит от доступности браузера; HTTP/HTML/JS проверки не заменяют её.

## Validation

Проверить все 16 версий и совпадение вывода, точность показанного кода относительно файлов, отсутствие скрытых импортов и ссылок скачивания. Пересобрать курс, выполнить test-course и строгую проверку OpenSpec. Прочитать новые ресурсы именно с основного URL, а не только из макета.
