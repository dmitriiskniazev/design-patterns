## ADDED Requirements

### Requirement: Проверка исполняемых сравнений
Инфраструктурная проверка MUST собирать четыре версии каждой темы сравнения в независимых временных папках и запускать их отдельными Python-процессами. Показанный код MUST совпадать с запущенными файлами. Обе стороны MUST выдавать ожидаемый одинаковый результат. Расширения MUST накладывать изменённые файлы на базовые без скрытых импортов из другой версии.

#### Scenario: Самостоятельные версии
- **WHEN** выполняется test-course
- **THEN** проверяются базовые и расширенные решения без паттерна и с паттерном всех тем с comparison-метаданными
