# Перенос сравнения в основной курс

Дата: 2026-10-21.

## Причина расхождения

Предыдущие изменения сравнений находились в /private/tmp/design-patterns-chapter-preview на порту 8001. Файлы основного интерфейса web/index.html и assets/app.js продолжали показывать отдельные шаги. Пользователь сообщил, что изменений не видит. Проверка HTTP-входа 8000 также показала отсутствие активного сервера; сервер запущен из корня проекта.

## Реализация

- fileComparison-метаданные Strategy, Adapter, State и Observer указывают исполняемые исходники в проекте. Существующее строковое поле comparison сохранено для теории остальных тем; совпадение имён полей при переносе обнаружено сборкой и исправлено.
- Новые независимые исходные версии находятся в before/, изменённые файлы — в before_extended/. Версии с паттерном используют действующие файлы уроков и отдельные compare_extended.py для одинакового сценария.
- Сборщик читает полный код и создаёт подсветку. Интерфейс основного курса показывает полные файлы в двух колонках и изменения при расширении. Копирование использует текст конкретного файла.
- Ссылки скачивания из интерфейса убраны. Генерация старых ZIP сохранена вне пользовательского пути.
- Версии ресурсов в web/index.html обновлены. Временные ссылки 8001 перенаправляют на основной вход 8000; прежние страницы сохранены в резервной копии.
- Остальные 21 тема сохраняют пошаговую подачу. Незавершённое изменение documentation-layout-reference не закрывается этой работой.

## Фактическая проверка

- `uv run --no-sync build-course`: 229 коротких листингов для 25 тем и полные файлы четырёх сравнений.
- `uv run --no-sync pytest tests/test_comparisons.py -q`: 21 тест прошёл, включая запуск всех 16 вариантов в независимых папках с игнорированием PYTHONPATH. Показанный код сверяется с исходниками; проверены overlay/replaces, отсутствующая точка запуска, дубли имён и выход пути за проект.
- `uv run --no-sync test-course`: 26 инфраструктурных тестов и проверки всех 25 тем прошли.
- `node --check assets/app.js`: успешно.
- Внешний check-ui.cjs исполняет реальные функции renderer и маршрутизации с собранными данными: проверены 233 состояния, соседние переходы, все полные файлы четырёх сравнений, две колонки в разметке, отсутствие скачиваний, нормализация старых ссылок к смысловым частям страницы.
- Основной сервер http://127.0.0.1:8000/web/ отдаёт index, app.js и course-data.js, побайтово совпадающие с файлами изменённого проекта. Проверялись URL с новой версией ресурсов, а не сервер макета.
- Сервер 8001 отдаёт страницу перенаправления на основной курс.
- `openspec validate --all --strict`: четыре объекта прошли до архивации.

## Ограничения

CUA возвращает пустые списки браузеров и приложений. Визуальное отображение, адаптивность, Tab/Escape, Clipboard и история в настоящем браузере не проверялись. Node-проверка логики и HTTP-сверка не являются браузерной проверкой. Следующий контроль при доступном браузере — открыть четыре темы на широком и узком экране и проверить копирование файлов.
