# Design

## Context
См. proposal.md. Указанные пользовательские файлы добавлены агентом, а для чтения курса Node-зависимости и учебные служебные MD не требуются.

## Decisions
Вход переносится в web/index.html. Локальные assets и исходники остаются на прежних местах; ссылки из нового входа указывают на ../assets и ../examples. Старые HTML-страницы направляют в новый вход.
README содержит цель, структуру, источники и команды; AGENTS отражает реальную структуру. Правила OpenSpec остаются в config.yaml. Данные уроков и подсветка остаются необходимыми ресурсами офлайн-интерфейса.
Playwright-проверки запускаются из /private/tmp с уже установленными временными инструментами. В проекте удаляются package-файлы, конфигурация и тесты этой обвязки.

## Risks / Trade-offs
Изменение относительных путей → 9 браузерных проверок, включая скачивание и локальное открытие без сети. Потеря полезной информации → перенос целей и ссылок в README; полная внешняя резервная копия 45 файлов с SHA-256. Инструкции для будущих изменений → актуализировать AGENTS и context.
