## Context

Четыре автономные версии уже содержат полные замыкания импортов. Текущий список после наложения расширений не задаёт порядок чтения.

## Goals / Non-Goals

Показывать весь код без дополнительных действий, сохраняя сравнения и лаконичные подписи. Не менять учебные примеры и не вводить модули интерфейса.

## Decisions

Сборщик упорядочивает файлы обходом в ширину от входа в порядке локальных импортов. Циклы и общие зависимости посещаются один раз; оставшиеся файлы сохраняются. Интерфейс читает этот порядок. Общие файлы совмещаются через общую подпоследовательность: при конфликте порядка повтор предпочтительнее перестановки. Карточки открыты и не ограничены по высоте. Ссылки файлов становятся якорями без фильтрации состава.

## Risks / Trade-offs

Полная реализация становится длиннее; это прямое требование пользователя. Широкие строки имеют только локальную горизонтальную прокрутку. Существующие deep links требуют проверки перехода и возврата в истории.
