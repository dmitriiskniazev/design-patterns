# Proposal

## Why
Пользователь просит современный Python-код и сообщает, что путь работы Adapter непонятен. Нужно улучшить код и начать объяснение с одного конкретного вызова и преобразования данных.

## What Changes
- State: match, именованные события и dataclass-контекст; Strategy: dataclass для контекста и неизменяемых данных.
- Adapter: внутренняя типизированная dataclass-квитанция; Pydantic проверяет внешние схемы SDK.
- Разбор Adapter: данные до/после → клиент → адаптер → выполнение → детали проверки и преобразования.
- uv автоматически читает зависимости запускаемого скрипта; тесты получают фиксированную версию Pydantic.

## Capabilities
### New Capabilities
Нет.
### Modified Capabilities
- `learning-interface`: прозрачный путь вызова и проверка несовместимых внешних данных.

## Impact
Учебные исходники и проверки, содержание курса, извлечение присваиваний в листинги, Makefile и правила авторства. Pydantic 2.14.1 проверен на Python 3.15.0b4.
