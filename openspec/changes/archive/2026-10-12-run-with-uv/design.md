# Design

Все цели Makefile используют uv с явным выбором Python 3.15 и отключённым поиском родительского проекта. Примеры и unittest используют стандартную библиотеку. Сборщик сохраняет зависимость Pygments в метаданных скрипта. В курсе отображаются прямые uv-команды, Makefile остаётся сокращением для разработки.

Первый запуск может скачать Python или Pygments; чтение готового курса остаётся офлайн. Новая структура пакета и дополнительные зависимости не нужны.
