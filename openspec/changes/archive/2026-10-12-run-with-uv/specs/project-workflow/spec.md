# Spec Delta

## ADDED Requirements

### Requirement: Запуск через uv
Python-примеры, тесты, сборка и локальный сервер MUST запускаться через uv с выбранным Python 3.15 или новее. Команды в учебных материалах MUST показывать запуск через uv; сокращения Makefile MUST использовать тот же способ.

#### Scenario: Запуск примера
- **WHEN** пользователь запускает указанную команду базового или расширенного примера
- **THEN** uv выбирает требуемый Python, и пример выполняется

#### Scenario: Проверка и просмотр курса
- **WHEN** пользователь запускает тесты, сборку или локальный сервер через Makefile
- **THEN** Python-команда выполняется через uv
