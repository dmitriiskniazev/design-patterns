# Proposal

## Why
Пользователь просит согласовать оформление кода с темой страницы, вводить конструкции постепенно через короткие листинги и писать только на Python.

## What Changes
- Курс и примеры переходят на Python >=3.15; C++ и переключатель языка удаляются после резервного копирования.
- Каждая готовая тема получает последовательность коротких объяснённых шагов вместо полного листинга на странице.
- Подсветка наследует светлую/тёмную палитру интерфейса. Копируется текущий фрагмент; полный исполняемый файл доступен отдельно.
- Ссылки хранят тему, раздел и шаг; старые ссылки с языком открывают соответствующий Python-раздел.

## Capabilities

### New Capabilities
Нет.

### Modified Capabilities
- `learning-interface`: только Python, постепенное представление кода и согласованное оформление.

## Impact
Меняются данные уроков, сборщик, интерфейс и команды Makefile. Документация отражает новый формат. Существующие Python-примеры и проверки сохраняются.
