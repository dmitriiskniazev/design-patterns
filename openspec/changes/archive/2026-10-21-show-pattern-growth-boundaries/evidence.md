# Проверка 2026-10-21

Пользователь уточнил: усложнение должно раскрывать архитектуру, цену перехода и расширяемость, а не дополнительные предметные правила. Четыре сравнения переработаны с простыми данными, явными зависимостями и второй осью изменения, которую паттерн не изолирует.

Полные исходники до и после расположены рядом в основном курсе. Расширение показывает новые и изменённые файлы; остальные наследуются из базовой версии. Сборщик проверяет stableFiles сравнением исходников. Исходный Adapter сохраняет общий helper и неизменность клиентов; исходный Observer допускает необязательную сигнализацию, сохраняя старый конструктор. State показывает необходимость изменения входящего перехода. Strategy сохраняет явный выбор в wiring.py.

Результаты:

- uv run --no-sync test-course: успешно, 28 инфраструктурных проверок и проверки всех 25 тем отдельными процессами. Среди них 16 автономных запусков отображаемых версий с точным сравнением stdout, классификация изменений и отклонение ложного заявления о неизменности файла.
- uv run --no-sync build-course: 229 коротких листингов, 25 уроков; полные сравнения пересобраны из исходников.
- node --check assets/app.js: успешно.
- Внешняя VM-проверка настоящего renderer: 25 тем, 233 состояния, четыре сравнения, полные файлы, две колонки, маршруты, переходы и отсутствие ссылок скачивания.
- HTTP read-back порта 8000: HTML и course-data.js побайтово совпали с текущими файлами; версия conceptual-20261021-1.
- openspec validate --all --strict: 4 элемента прошли, ошибок нет.

Браузерная проверка геометрии, узкого экрана, клавиатуры и буфера обмена не выполнена: браузерная поверхность недоступна. VM и HTTP не подтверждают визуальное отображение. Резервная копия до переработки: /private/tmp/design-patterns-conceptual-growth-20261021/before.tar.gz.
