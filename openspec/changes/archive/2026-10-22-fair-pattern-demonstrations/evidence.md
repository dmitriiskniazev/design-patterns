# Реализация и проверка

## Содержательные изменения
Ревью всех25 тем выполнено тремя агентами. Код переработан в15 темах; Builder получил только честные пояснения о преимуществе прямого конструктора при готовых данных.

- Command: реальные история и отмена в обоих подходах; расширение Insert→Clear→undo→undo совпадает.
- Memento: исходный снимок корректно копирует данные; до — независимые plain_canvas/plain_colored_canvas, после — владелец save/restore и непрозрачная история. Расширение сохраняет точки и цвет BrushColor; History не знает формат снимка.
- Iterator: iter/reversed и независимые курсоры вместо искусственного ручного индекса.
- Interpreter: одинаковое условие Python AND(tests OR typing), вложенность видна в запуске.
- Visitor: узлы до паттерна не содержат accept/Visitor.
- Chain: исключена повторная проверка имени.
- Factory Method: независимый MarkdownDocument; одинаковая очистка и проверка текста в обеих версиях. Общий Exporter.export сохраняет эти шаги при новом продукте.
- Abstract Factory: один параметр темы, одинаковая операция screen(theme)→str; нет искусственного смешивания тем. Указано, что для этой маленькой модели функция проще.
- Singleton: обычный явный счётчик тоже сохраняет последовательность; подмена счётчика до паттерна не импортирует Singleton. Пример показывает цену скрытого общего состояния.
- Prototype: изменённый при выполнении шаблон и два независимых клона видны в выводе.
- Facade: два реальных клиента до; после они используют общий сценарий. Расшифровка меняет фасад, а не клиентов.
- Proxy: кеширование одинаково до/после; конкретный Loader вынесен в независимый asset_loader.py.
- Decorator: обе стороны обеспечивают gain→limit и limit→gain.
- Dependency Injection: один и тот же фиксированный источник и смещение до/после.
- Flyweight: одинаковые посадки, сравнение числа Style, без обещаний экономии байтов.

Метаданные объединены из /private/tmp/{creation,structural,behavioral}-guide-updates.json. Исходники и селекторы коротких фрагментов согласованы. Сборщик показывает команды запуска исходных решений с __main__, функции без него обозначены отдельно. Резервные копии: /private/tmp/creation-examples-before-20261022.tgz; /private/tmp/structural-examples-before-20261022.tar.gz; /private/tmp/behavioral-before-example-fixes-20261022.tar.gz; /private/tmp/design-patterns-content-before-fair-demos-20261022.tgz.

## Исправления при интеграции
Первая сборка выявила отсутствующего owner asset_loader.py на вспомогательной карте Proxy; добавлен узел. Первичный инфраструктурный прогон до успешной пересборки обнаружил старые данные, что устранено пересборкой. После согласования данных полная проверка прошла. Дополнительная проверка пустого текста Factory Method потребовала обновить старый тест, допускавший пустой документ; одинаковый отказ обеих версий теперь проверяется явно.
