# Decisions
examples/<pattern>/{base,extended}/{without_pattern,with_pattern}/main.py. В каждом каталоге локальные роли и test_example.py. Неизменившиеся маленькие модули повторяются намеренно; импортов между снимками нет. База не содержит новых участников расширения; расширение сохраняет прежние возможности там, где добавляет альтернативу. Композиционные расширения Builder, Mediator, Prototype, Singleton не требуют искусственных изменений инфраструктуры.

Сборщик читает полный directory каждого варианта без наложения базы. Diff вычисляется между файлами с одинаковыми именами; повторяющийся код по-прежнему можно показать на сайте один раз. Main и ролевые переименования получают aliases старых ссылок.

# Preservation
До переноса создан /tmp/design-patterns-before-variants-20261027.bundle; исходники также сохранены вне проекта для сравнения. Flyweight: базовый Shared теряет преждевременное поле variant, поэтому ожидаемый repr меняется одинаково на обеих сторонах.
