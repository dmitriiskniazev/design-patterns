## MODIFIED Requirements

### Requirement: Проверка полного набора
Документированная общая команда проверки MUST находить все каталоги учебных примеров и запускать их pytest-проверки через uv отдельными процессами, прекращая проверку при первой ошибке. Новая тема MUST NOT требовать ручного добавления в список запуска.

#### Scenario: Новая тема
- **WHEN** добавлен каталог examples/<pattern>/<stage>/<approach> с main.py и test_example.py
- **THEN** общая команда проверяет его вместе с остальными темами без конфликтов одноименных модулей

### Requirement: Проверка исполняемых сравнений
Инфраструктурная проверка MUST собирать четыре версии каждой темы сравнения в независимых временных папках и запускать их отдельными Python-процессами. Показанный код MUST совпадать с запущенными файлами. Обе стороны MUST выдавать ожидаемый одинаковый результат. Каждый вариант MUST иметь полный собственный набор файлов без скрытых импортов из другой версии. Тесты каждого варианта MUST запускаться отдельным процессом, а проверки поведения MUST сопровождаться сравнением ожидаемых результатов обеих сторон.

#### Scenario: Самостоятельные версии
- **WHEN** выполняется test-course
- **THEN** проверяются базовые и расширенные решения без паттерна и с паттерном всех тем с comparison-метаданными
