# Design

## Context
Предыдущее ревью ошибочно приняло прежние имена как неизменный контракт. Пользовательское уточнение отменяет этот контракт. Четыре независимых набора сохраняют назначение; заменяется50 имен существующих файлов.

## Goals / Non-Goals
Показать две оси сравнения прямо в именах и изменения между базой и расширением. Не создавать копии или wrappers, не добавлять новую вкладку и инструменты проекта.

## Decisions
- Пары without_pattern/with_pattern и общий суффикс _extended прямо соответствуют сторонам и режиму UI.
- Старые имена остаются только в aliases и исторических документах. Существующие файлы переименовываются.
- Diff рассчитывается сборщиком по строкам: entry сравнивается с entry базовой стороны, ролевой файл — по имени. Новый файл целиком добавленный. Удаления красные с минусом, добавления зеленые с плюсом, различение не зависит только от цвета.
- Один переключатель в расширении меняет отображение обеих колонок; копирование всегда возвращает текущий исполняемый исходник.

## Risks / Trade-offs
- Смена50 путей → сборка, автономные100 наборов, aliases и браузерный readback.
- Diff может скрыть исполняемый файл → доступен обычный полный режим, буфер не включает удалённые строки/маркеры.
- Цветовые акценты отходят от монохромности → ограничить их только смысловым diff.
