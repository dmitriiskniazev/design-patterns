# Повторная приемка имен и diff

## Причина пересмотра
Пользователь справедливо отверг асимметричные main.py/run_extended.py. Прошлое ревью приняло историческое предписание как неизменный контракт и потому не проверило имена против пользовательского критерия ясности. Прежние100/100 не являются доказательством отсутствия недостатков; эту область проверили заново.

## Реализация
- Переименованы50 существующих входных файлов: main.py→with_pattern.py, run_extended.py→with_pattern_extended.py. Без wrappers, число Python-файлов осталось180. Пары without_pattern.py/with_pattern.py используют общий суффикс _extended.py.
- Обновлены метаданные, sourceFiles, команды, ZIP, README, AGENTS и config. Старые имена доступны через aliases, каноническая ссылка использует новые.
- Расширение имеет один checkbox «Изменения», по умолчанию включенный. Он показывает добавленные/удаленные строки относительно базы той же стороны. Неизменённые файлы отображаются обычным кодом. Точки входа сопоставлены по роли независимо от имени.
- Diff хранится на ссылке версии, исходники сохраняются без изменений. Copy берет точный текущий source.code, а не текст diff DOM. Общий файл не объединяется, если у сторон разные изменения.

## Независимое ревью
review_structure одобрил схему имен до реализации; review_code независимо проверил50 переименований,100 наборов и aliases после реализации root. review_code также проверил diff, написанный review_structure:6 targeted тестов прошли, все118 extension refs точно восстанавливают оба исходника, дополнительные пробы multiline/blank/CRLF прошли. Замечаний к проверенным изменениям не найдено. Текст diff имеет контраст≥5.71:1, маркеры≥5.79:1; +/− и текст для screen reader дополняют цвет.

## Ограничения
Проверен Chromium, не Safari/Firefox и не физическое устройство. Clipboard проверен по аргументу API, системный буфер отдельно не читался. Diff сравнивает реальные полные файлы наборов: общий ролевой модуль с обеими реализациями одинаков в базе и расширении и поэтому не подсвечивается. Проверка всего курса по новой шкале не объявляется; проведена независимая приемка конкретных изменений и регрессионные проверки.

Финальная синхронизация проверена: действующие specs не содержат main.py/run_extended.py; openspec validate --all --strict:3/3,0 ошибок. Ruff:189 файлов соответствуют форматированию.
