## ADDED Requirements

### Requirement: Наблюдаемый выигрыш Strategy
Глава Strategy MUST прямо указывать, что для двух коротких стабильных формул исходный match проще. Расширение MUST демонстрировать передачу новой функции в Enemy без изменения Enemy, Move, Behavior и встроенной фабрики; выбор по конфигурационному имени MUST объясняться как отдельная необязательная точка регистрации. Смена синтаксиса match на if MUST NOT объявляться архитектурным улучшением.

#### Scenario: Новый алгоритм вне встроенного списка
- **WHEN** передаётся guard(home) или тестовая функция с контрактом Move
- **THEN** Enemy выполняет её и сохраняет результат, хотя встроенный Behavior не содержит этого алгоритма

#### Scenario: Выбор простого решения
- **WHEN** есть только две неизменяемые формулы
- **THEN** глава рекомендует простой match и объясняет, что if подходит для произвольных булевых условий
