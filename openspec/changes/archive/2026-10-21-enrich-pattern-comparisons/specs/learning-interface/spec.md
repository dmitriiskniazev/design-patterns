## ADDED Requirements

### Requirement: Содержательные сценарии сравнения
Сравнения Strategy, Adapter, State и Observer MUST показывать серию действий и результат, зависящий от данных или текущего состояния. До и после паттерна MUST сохраняться одинаковые предметные правила и результат. Расширение MUST добавлять одну возможность, а текст MUST явно называть необходимые изменения, сохранённые части и ограничения учебной модели. Полный исполняемый код MUST оставаться доступным по файлам в основном интерфейсе без скачивания.

#### Scenario: Несколько ходов
- **WHEN** читатель запускает Strategy
- **THEN** видит несколько допустимых ходов с препятствиями; охрана области добавляется отдельным поведением, а пример не обещает поиск пути

#### Scenario: Набор треков
- **WHEN** читатель запускает Adapter
- **THEN** получает согласованные единицы и ошибки для нескольких треков; при подключении второго API клиент сохраняется

#### Scenario: Позиция проигрывания
- **WHEN** читатель запускает State
- **THEN** загрузка, воспроизведение и запреты зависят от состояния; пауза сохраняет позицию, запрещённая операция не повреждает её

#### Scenario: Серия измерений
- **WHEN** читатель запускает Observer
- **THEN** журнал и статистика получают измерения, а новая сигнализация не повторяет тревогу на каждом замере выше порога
