# Результат

Все25 тем полностью заменены абстрактными ролями. Предыдущие игры, звук, документы, датчики, часы, рисунки, SQL и прочие предметные модели удалены из действующих examples/content. Числа и метки A/B служат только наблюдаемыми значениями. Исходники плоские, разложены по ролям; четыре запуска самостоятельны: without_pattern.py, main.py, without_pattern_extended.py, run_extended.py.

Все25 тем переведены на единый fileComparison с полными транзитивными наборами, явным дополнением/заменой файлов, одинаковыми входами/результатами и стабильными участниками. Guide: ровно две пары фрагментов; термины, роли, компактные схемы и границы пользы. В100 наборах один и тот же исходник используется для страницы, копирования и проверки исполнения. Исторические vN-ссылки сохраняют прежнее отображение индексов (четыре для прежних4 comparison-тем, три для остальных21); старое отсутствующее имя файла заменяется новым входным.

README, AGENTS и config.yaml согласованы с прямым новым требованием пользователя, заменив прежние обязательные предметные сюжеты. Действующие спецификации обновляются; архивная история сохраняется.

## Проверки
- Сборка:50 коротких листингов25 тем; каждый≤12 непустых строк.
- Сборка метаданных:100 наборов изолированно скопированы и запущены,50 пар дают побайтово одинаковый stdout.
- test-course:143 инфраструктурных теста и25 тестов свойств паттернов прошли; все25 тем проверены отдельными процессами. Инфраструктурные проверки теперь запускают100 сравнений, а не16; устаревший путь для21 не-comparison темы удалён.
- После дополнения схем общим результатом:31 guide-проверка прошла.
-50 корневых базовых/расширенных точек входа выполнены отдельно; устаревшие генерируемые кеши удалены.
- Реальный app.js через Node VM:319 пар полных файлов,100версий50режимов,28 общих выбранных исходников показаны один раз. Проверены точный копируемый текст и отдельные номера строк,259 переключений из каждого файла,75 состояний вкладок, legacy-маршруты и fallback старой присланной ссылки Strategy.
- Поиск прежних предметных слов в examples/content не нашёл совпадений. В AGENTS/config запрещающие формулировки и слово Markdown относятся к правилам проекта, не к модели примеров.
- Strategy SVG реально отрисован rsvg-convert и просмотрен; общий результат теперь связан с обеими сторонами. Файл /private/tmp/abstract-strategy.png.
- HTTP localhost:8000: index.html и course-data.js побайтово совпадают с исходниками. Версия ресурсов abstract-mechanics-20261022-1.
- Браузер недоступен: cua.getState вернул apps:[],browsers:[]. Визуальная проверка страницы в реальном браузере не выполнена; рендер, маршруты, обработчики и отдельная схема проверены.
