## MODIFIED Requirements

### Requirement: Собранный код доступен для чтения
Во вкладке «Полная реализация» пользователь MUST выбирать ось двух колонок: «Без паттерна / С паттерном» либо «Без расширения / С расширением». Для первой оси общий переключатель MUST выбирать базовый пример или расширение, для второй — реализацию без паттерна или с паттерном. Файлы каждой стороны MUST выбираться независимо и принадлежать выбранной версии. Код MUST совпадать с исходником; номера строк MUST NOT попадать в копирование. Прямая ссылка и история MUST сохранять ось, вариант и оба файла; прежние base/extended и vN-ссылки MUST работать. Одинаковый выбранный полный файл MUST показываться один раз с явной подписью, кроме случая разных отображаемых diff. На узком экране колонки MUST располагаться последовательно.

#### Scenario: Чтение итогового файла
- **WHEN** пользователь выбирает просмотр собранного кода
- **THEN** видит состав выбранных версий, назначение выбранных файлов и полный код в соответствии с осью сравнения

#### Scenario: Сохранение постепенного формата
- **WHEN** пользователь открывает шаг без выбора полного файла
- **THEN** во вкладке примеров отображаются короткие фрагменты, а полные файлы остаются скрытыми

#### Scenario: Сравнение расширения
- **WHEN** выбрана ось «Без расширения / С расширением» и реализация с паттерном
- **THEN** слева показан базовый вариант с паттерном, справа его расширение

#### Scenario: Сравнение исходного решения
- **WHEN** при сравнении расширения выбрана реализация без паттерна
- **THEN** обе колонки относятся к исходному решению: базовому и расширенному

#### Scenario: Возврат к сравнению
- **WHEN** открыта сохранённая ссылка либо выполнен переход назад в истории
- **THEN** восстановлены ось, выбранный вариант и оба файла, а заголовки соответствуют версиям
