# Design

## Context
guide.versions уже содержит четыре независимые версии:0 без паттерна,1 с паттерном,2 расширение без паттерна,3 расширение с паттерном. Новая возможность — выбор пары из них.

## Goals / Non-Goals
Сохранить две колонки и лаконичные контролы. Не дублировать исходники и не добавлять новые вкладки или зависимости.

## Decisions
- Ось pattern использует пары0/1 либо2/3; ось extension —0/2 либо1/3.
- Заголовки колонок отражают ось, вторичный выбор определяет фиксированный вариант.
- Прежние URLs base/extended остаются сравнением паттерна; новые extension/with-pattern|without-pattern кодируют сравнение расширения.
- Выбор файла независимый. Diff расширенной стороны сравнивается с её собственной базой и явно подписывает базовый файл, даже если слева выбран иной файл. Базовая сторона отображается полным исходником.
- При смене оси/варианта открываются соответствующие входы; при возврате через историю восстанавливаются сохранённые файлы.

## Risks / Trade-offs
- Потеря оси при смене вкладки/истории → браузерные проверки прямых ссылок, reload, back/forward и переходов между темами.
- Ошибочное объединение одинакового файла с разными diff → сохранить проверку идентичности представления.
