# Приемка двух осей сравнения

## Изменение
Во вкладке полной реализации появился компактный выбор «Сравнить». Ось без/с паттерном выбирает пары версий0/1 или2/3 по базовому/расширенному режиму. Ось без/с расширением выбирает0/2 или1/3 по реализации без/с паттерном. Исходники, сборщик и зависимости не менялись; использованы существующие app.js/app.css.

Заголовки колонок соответствуют оси. Оба файла выбираются независимо. Смена оси/варианта открывает соответствующие входы; история/ссылки сохраняют ось, вариант и файлы. Базовая колонка показывает полный файл; diff справа в сравнении расширения подписывает собственный базовый файл, даже если слева выбран иной файл. Общий неизменный исходник показывается один раз. Copy всегда берет полный исходник.

## Независимое ревью
Автор UI:review_structure. Независимый проверяющий:review_code. Проверены parse/hash/sourcePair, обработчики, учет compare/implementation в раннем выходе renderer и памяти, заголовки, diff-aware дедупликация, copy и focus. Конкретных дефектов не найдено.

Авторский внешний прогон:150 случаев по25 темам. Независимый внешний прогон:100 комбинаций(25×4), обратимое восстановление ссылок и сохраненного состояния;100 прежних vN-ссылок. node --check assets/app.js успешен. Проверочные скрипты находятся вне проекта: /tmp/check-source-axis.cjs и /tmp/review-course-axes.cjs.

## Браузер
Основной агент проверил /tmp/check-comparison-axes.cjs в отдельном headless Chromium, file://, временный профиль. Успешно:800 состояний(25тем×4пары×2палитры×4ширины320/768/1024/1440), правильные файлы/заголовки, отсутствие переполнения и JS ошибок, оба контролла, independent selection/reload/tab return/history, dedup, copy обеих сторон, diff checkbox клавиатурой, legacy URLs. Прогон завершился exit0;0 ошибок JS и0 переполнений. Проверены скриншоты светлой темы и320px. Итог:/tmp/comparison-axes-result.json.

## Границы
Safari/Firefox и физические мобильные устройства не проверяются. Copy проверяется по точному аргументу перехваченного clipboard API; системный буфер не читается. Прежний Python-набор175 тестов не запускался повторно: Python, учебные исходники и данные этой правкой не затронуты. Проверки относятся к новой навигации и представлению, не являются новой полной оценкой курса.

Спецификация синхронизирована, изменение архивировано. Финальный openspec validate --all --strict:3/3,0 ошибок; node --check успешен.
