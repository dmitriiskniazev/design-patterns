# Проверка 2026-10-21

Полная реализация показывает две стороны с независимыми select файлов и одним общим radio-переключателем базового/расширенного примера. Во всех25 темах есть100 точных наборов (по4), объединённых в50 пар. Код сохраняет шрифт, подсветку, номера строк, копирование и переходы к локальным зависимостям. На узком экране стороны идут последовательно. Одинаковый выбранный файл не дублируется.

В21 теме исходный baseline разделён: naive.py и before_extension.py собираются отдельно с транзитивными локальными импортами. Расширенные файлы отмечены как новые/изменённые/неизменённые по реальному исходнику. Старые vN-ссылки переводятся через legacyVersionIndices; бывший v3 в21 теме по-прежнему означает расширение с паттерном. Новый URL хранит режим и оба имени файла; последнее сравнение темы сохраняется при переключении вкладок.
