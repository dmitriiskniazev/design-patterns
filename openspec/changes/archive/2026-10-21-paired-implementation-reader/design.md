# Решение

guide.pairs задаёт before/after для base и extended. В существующих четырёх сравнениях используются готовые staged-наборы; в остальных21 темах naive.py и before_extension.py собираются с транзитивными локальными зависимостями отдельно. Одного смешанного baseline-набора больше нет.

Общий режим — radio-переключатель. Каждая колонка имеет свой select файла, назначение, зависимости и полный код с номерами строк. На широком экране две колонки, на узком последовательные. Текст, копирование и подсветка остаются точными. При выборе одного общего файла в обеих колонках полный текст показывается один раз с явной подписью.

Маршрут implementation/base/left.py/right.py или implementation/extended/left.py/right.py сохраняет сравнение. legacyVersionIndices переводит прежние vN-ссылки; в21 темах прежний v3 означал расширение с паттерном. Возврат к вкладке восстанавливает последнее сравнение темы. Неизвестные файлы заменяются входными файлами соответствующей стороны.
