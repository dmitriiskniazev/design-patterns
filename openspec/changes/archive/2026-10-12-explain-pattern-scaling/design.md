# Design

## Context
См. proposal.md. Базовые шаги уже извлекаются по AST и показываются по одному. Упражнения пока не имеют разбора расширения.

## Decisions
Добавить раздел «Расширение» и ссылку на него из практики. Один renderer шагов обслуживает базовый и расширенный разбор. У каждого потока отдельные шаги, полный файл и команда запуска; deep link хранит поток и шаг.
Добавить standalone учебные варианты extended.py и before_extension.py. Контекст или клиент копируется без изменений, чтобы итоговый файл можно было запускать отдельно; равенство стабильных блоков проверяется при верификации. Для Strategy и Adapter тесты также используют исходный клиент с новыми функциями/адаптерами.
Материалы показывают реальные ограничения: выбор и подключение новой стратегии остаются снаружи, адаптер содержит новую конверсию, State требует изменения перехода On. Для фиксированного небольшого автомата таблица может быть проще классов.

## Risks / Trade-offs
Скрытая подмена «масштабирования» → объяснять добавление требований, а не производительность. Слишком ранний показ решения → отдельная ссылка из задания. Длинные листинги → прежний лимит 12 строк. Копии учебного контекста расходятся → проверка AST и тесты с базовым клиентом.
