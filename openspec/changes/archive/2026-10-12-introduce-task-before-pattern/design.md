# Design

Для каждой готовой темы task хранит цель, правила и конкретный пример результата; startingPoint объясняет начальный подход. Отдельный problem описывает последствия новых требований. В теории task предшествует сетке с объяснениями, участниками и кодом, поэтому первая видимая постановка не зависит от ширины экрана.

В первом шаге базового и расширенного разбора показывается соответствующая задача. Последующие шаги сохраняют короткий формат. Прямые ссылки, номера шагов и исходники не меняются. Статический урок Strategy получает ту же постановку из данных курса.
