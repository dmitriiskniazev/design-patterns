# Чтение полной реализации по файлам

## Why
Длинный список версий и раскрытий затрудняет чтение целой реализации. Нужен один видимый файл, ясный состав выбранной версии и переходы между связанными частями.

## What Changes
Во вкладке полной реализации появляется выбор варианта, список его файлов и одна область кода с назначением файла, номерами строк, копированием и ссылками на локальные зависимости. По умолчанию открывается запуск варианта с паттерном. Выбранные версия и файл входят в ссылку.

## Impact
Метаданные сборщика, интерфейс, оформление и проверки. Исходники учебных примеров не меняются.
