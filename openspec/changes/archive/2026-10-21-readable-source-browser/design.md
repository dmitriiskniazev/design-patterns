# Решение

Источники сохраняются в существующем дедуплицированном реестре. Сборщик добавляет назначение файла, локальные импорты и имя входного файла. Выбор версии показывает только относящиеся к ней файлы; тесты идут после кода. Область чтения содержит один полный исходник без вложенных раскрытий и длинных служебных путей.

Маршрут implementation/vN/filename.py задаёт версию и файл; неизвестные значения безопасно заменяются входным файлом версии с паттерном. Переходы по зависимостям используют тот же маршрут. Между вкладками сохраняется последний выбор темы, история и прямая ссылка его восстанавливают. Номера строк расположены вне code и не попадают в копирование. На узком экране список файлов располагается над кодом и прокручивается локально.

Подсветка и шрифт кода сохраняются. Команда запуска показывается один раз для выбранного варианта; базовые функции без входного файла не получают вымышленной команды.
