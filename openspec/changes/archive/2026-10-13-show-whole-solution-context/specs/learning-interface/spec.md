# Spec Delta

## ADDED Requirements

### Requirement: Общая картина решения
Каждый готовый базовый и расширенный разбор MUST предоставлять схему участников с обязанностями, связями и конкретным примером выполнения. Каждый короткий фрагмент MUST объяснять своё место в этой схеме. При прямом открытии шага схема MUST оставаться доступной, а участники MUST позволять перейти к соответствующему коду.

#### Scenario: Изучение частей в контексте
- **WHEN** пользователь открывает разбор или отдельный шаг
- **THEN** может увидеть участников целого решения, проследить конкретный вызов и понять, какую часть показывает текущий листинг

#### Scenario: Переход от схемы к коду
- **WHEN** пользователь выбирает участника решения
- **THEN** открывается соответствующий шаг этого же базового или расширенного разбора

### Requirement: Собранный код доступен для чтения
Пользователь MUST иметь возможность посмотреть полный итоговый Python-файл на странице отдельно от коротких шагов. Показанный текст MUST совпадать с исполняемым скачиваемым исходником; код MUST поддерживать общую тему и локальное чтение. Полный файл MUST показываться по явному выбору пользователя.

#### Scenario: Чтение итогового файла
- **WHEN** пользователь выбирает просмотр собранного кода
- **THEN** видит подсвеченный полный файл соответствующего решения и может вернуться к коротким фрагментам

#### Scenario: Сохранение постепенного формата
- **WHEN** пользователь открывает шаг без выбора полного файла
- **THEN** отображается один короткий листинг с контекстом, а собранный код не показывается автоматически
