## Decisions
Режим и файл являются разными уровнями выбора. Явное переключение режима начинает чтение его запуска заново. Прямая ссылка на общий файл остаётся точной и показывает предупреждение, что он не менялся, вместе с переходами к изменениям. Служебные sourceFiles комплекта сохраняются; отдельная область чтения использует замыкание импортов своего запуска. Четыре подробно разложенные comparison-темы сохраняют полный заявленный набор с неизменяемыми участниками.

## Validation
Регрессия на присланной ссылке и переключение из каждого файла каждой темы в оба режима. Изолированный запуск каждого отображаемого набора с паттерном. Проверка исключения посторонних исходных решений и совпадения нового требования с заданием. Полный test-course, реальный renderer через Node VM, HTTP read-back. Визуальная проверка — при доступности браузера.
