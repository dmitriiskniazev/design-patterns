# Spec Delta

## MODIFIED Requirements

### Requirement: Запуск через uv
Проект MUST содержать pyproject.toml, uv.lock, пакет в src и инфраструктурные проверки в tests. Python-примеры, тесты, сборка и локальный сервер MUST запускаться через uv с выбранным Python 3.15 или новее. Команды в учебных материалах MUST показывать запуск через uv. Проект MUST NOT требовать make или содержать Makefile. Скачиваемые учебные комплекты MUST запускаться без установки пакета курса.

#### Scenario: Запуск примера
- **WHEN** пользователь запускает указанную команду базового или расширенного примера
- **THEN** uv выбирает требуемый Python, и пример выполняется

#### Scenario: Проверка и просмотр курса
- **WHEN** пользователь запускает указанную uv-команду тестов, сборки или локального сервера
- **THEN** Python-команда выполняется без make

#### Scenario: Скачанный пример
- **WHEN** пользователь распаковывает комплект и выполняет указанную команду
- **THEN** пример или его тесты запускаются через uv независимо от пакета курса

### Requirement: Проверка полного набора
Документированная общая команда проверки MUST находить все каталоги учебных примеров и запускать их pytest-проверки через uv отдельными процессами, прекращая проверку при первой ошибке. Новая тема MUST NOT требовать ручного добавления в список запуска.

#### Scenario: Новая тема
- **WHEN** добавлен каталог examples/<pattern>/python с test_*.py
- **THEN** общая команда проверяет его вместе с остальными темами без конфликтов одноименных модулей
