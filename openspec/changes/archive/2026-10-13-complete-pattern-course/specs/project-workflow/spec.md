## ADDED Requirements

### Requirement: Проверка полного набора
Команда make test-python MUST находить все каталоги учебных примеров и запускать их pytest-проверки через uv отдельными процессами. Новая тема MUST NOT требовать ручного добавления в список запуска.

#### Scenario: Новая тема
- **WHEN** добавлен каталог examples/<pattern>/python с test_*.py
- **THEN** общая команда проверяет его вместе с остальными темами без конфликтов одноименных модулей
