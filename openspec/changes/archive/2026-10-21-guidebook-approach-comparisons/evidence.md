# Проверка guide book — 2026-10-21

Причина: полные повторяющиеся файлы мешали сравнивать подходы. Пользователь запросил формальные главы, рисунки, дополнительные примеры, скрытые полные реализации и акцент на разнице.

Результат: семь guide-глав (Strategy, Adapter, State, Observer, Command, Composite, Decorator), семь объединённых схем, 16 пар исходных фрагментов, три оси роста и два дополнительных иллюстративных применения на главу. Общие участники схем, начало/завершение фрагментов и одинаковые полные файлы не дублируются. Полные реализации закрыты по умолчанию; состав версий, команды и отметки изменений доступны внутри справочного раскрытия. Подсветка использует прежние code-window и highlight.css.

Проверки:

- uv run --no-sync build-course: 229 коротких листингов, 25 тем, семь guide-глав.
- uv run --no-sync test-course: 38 инфраструктурных тестов и все темы отдельными процессами прошли.
- uv run --no-sync pytest: 38 passed; после проверки фрагментов добавлены точные проверки восстановления исходного листинга из общих и различающихся частей.
- node --check assets/app.js: успешно.
- Внешняя VM-проверка настоящего renderer: 25 тем, 203 состояния чтения, семь SVG, 16 пар, закрытые раскрытия, уникальность полных файлов, прежние маршруты, линейная навигация и отсутствие скачивания.
- Все семь SVG отрисованы установленным rsvg-convert без скачивания средств проверки. Рисунки Strategy, Composite и Observer просмотрены; длинные стрелки исправлены, чтобы не пересекать промежуточные блоки.
- Основная выдача http://127.0.0.1:8000/web/ сверена побайтово с HTML, JS, данными и CSS. Версия ресурсов guidebook-20261021-1.
