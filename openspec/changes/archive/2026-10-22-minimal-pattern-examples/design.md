## Decisions
Не уменьшать код уплотнением строк или удалением типов. Убирать сценарии и правила, не объясняющие паттерн: второй независимый объект из запуска, дублирование print, проверки пустого текста и принадлежности клиента комнате. Воспроизведение существенных ошибок автомата и несовместимость единиц API остаются частью механики. Выбор закрытых вариантов остаётся match/StrEnum. Файлы данных, реализации и запуска сохраняются.

## Validation
Сравнить число непустых строк отображаемых наборов до/после. Проверить все25 тем, независимый запуск наборов, одинаковый результат пар, реальный renderer и переключатель расширения. Не обещать уникального выигрыша паттерна при минимальном масштабе: простая функция может быть удобнее.
