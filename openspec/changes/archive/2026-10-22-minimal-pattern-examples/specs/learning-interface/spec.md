## ADDED Requirements

### Requirement: Минимальный учебный пример
Глава MUST показывать механику паттерна и ровно одно расширение через два коротких парных сравнения. Запуск MUST использовать один небольшой сценарий; дополнительные независимые объекты, ошибки данных и повторы MUST оставаться в тестах, если не объясняют сам паттерн. Примеры MUST NOT добавлять валидацию и предметные правила только ради объёма общего процесса. Сокращение MUST сохранять читаемость, явные типы, работающие файлы и равноправие вариантов. Предположения о допустимых входах MUST быть названы явно.

#### Scenario: Чтение короткого примера
- **WHEN** читатель открывает вкладку примеров
- **THEN** видит одну пару основной операции и одну пару единственного расширения

#### Scenario: Минимальный запуск
- **WHEN** читатель открывает запуск Observer или Strategy
- **THEN** видит один датчик либо одного противника; независимость нескольких экземпляров проверяется тестами
