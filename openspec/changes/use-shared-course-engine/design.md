# Design

## Context

Исходное дерево сохранено в /private/tmp/course-engine-extraction-baseline/courses-before.tar.gz. guide, все 25 глав, hash-маршруты, старый /web/ и полные исходники принадлежат курсу. Сам движок не подменяет формат уроков.

## Goals / Non-Goals

**Goals:** получать общие ресурсы из wheel, сохранить старые URL и пространство имён patterns.

**Non-Goals:** редизайн, изменение материала, добавление тем, релиз на удалённом сервере.

## Decisions

Ресурсы копируются после локальных адаптерных модулей; общие файлы отсутствуют в авторском дереве. site.package накладывает ресурсы пакета и вызывает общий механизм офлайн-снимка; namespace patterns и прежний scope сохраняются.

Движок устанавливается из публичного GitHub-репозитория; оба курса фиксируют полный SHA `9238e04d05dbf295635ede6888f09e4bc0706cc4`. uv.lock содержит тот же разрешённый коммит. Локальный wheel использовался для первоначальной проверки и затем удалён из зависимостей. CI получает пакет без соседнего checkout и нового секрета.

## Risks / Trade-offs

- Удаление копий → резервная копия и две сборки: сначала с overlay, затем после удаления.
- Изменение DOM → адаптер передаёт область inert и подписи; браузерная проверка отдельно от Node.
- Другие незавершённые changes → не менять их статусы и не архивировать.

## Migration Plan

Подключить wheel, проверить сборку; удалить только ресурсы, поставляемые wheel; повторить проверки и сравнить контрольные суммы материалов. Откат: восстановить адаптеры, dependency/lock и удалённые ресурсы из резервной копии.
