# Spec Delta

## Purpose

Обеспечивает сборку курса с общими ресурсами интерфейса из зафиксированного пакета при сохранении собственного формата материалов и существующих пользовательских ссылок.

## ADDED Requirements

### Requirement: Общие ресурсы поступают из установленной зависимости

Сборка SHALL получать настройки, темы, шрифты с лицензиями и общие компоненты просмотра из зафиксированного course-engine. Авторское дерево SHALL NOT содержать поддерживаемых вручную копий общих ресурсов. Ресурсы SHALL копироваться только в результат сборки.

#### Scenario: Нет соседнего checkout движка
- **WHEN** курс с Git-зависимостью и uv.lock установлен из чистого клона
- **THEN** штатная команда собирает сайт со всеми ресурсами без ../course-engine

### Requirement: Миграция сохраняет поведение курса

Подключение пакета SHALL сохранять учебные материалы, исполняемые исходники, существующие команды и URL. Ключи настроек SHALL сохранять пространство patterns; миграция старых editor/theme SHALL продолжать работать.

#### Scenario: Читатель открывает прежнюю ссылку
- **WHEN** после подключения пакета открыт прежний URL с выбранным режимом и файлом
- **THEN** доступны тот же материал, исходники и сохранённые настройки
