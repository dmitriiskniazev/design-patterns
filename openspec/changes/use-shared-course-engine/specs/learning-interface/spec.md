# Spec Delta

## MODIFIED Requirements

### Requirement: Функциональные модули интерфейса
Адаптер курса MUST находиться в web/src с navigation/lesson/code_viewer/settings; app.js MUST соединять части явными импортами. Общие ресурсы MUST поставляться зафиксированным course-engine и копироваться только в результат сборки, без поддерживаемых копий в web/src и web/public. Каталоги и нормализация настроек MUST иметь единые источники данных; собственный скрытый набор цветов в панели MUST отсутствовать.

#### Scenario: Добавление темы
- **WHEN** тема добавлена в каталог
- **THEN** сборщик и панель используют её без параллельного списка названий в HTML
