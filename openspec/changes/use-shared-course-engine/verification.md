# Проверка выделения course-engine

Дата: 2026-11-03. Локальная реализация и автоматические проверки выполнены. Браузерная приёмка не завершена; удалённый репозиторий, публикация и коммиты не создавались.

## Реализация

- Пакет `course-engine` 0.1.0: ресурсы через importlib.resources, общие настройки и панель, темы, 9 локальных гарнитур с лицензиями, копирование, заголовки и просмотр одного/двух файлов, выравнивание и подсветка.
- Контракт самостоятельного курса v1 и пример `examples/minimal/course.json`; текст `body` — обычные абзацы, без Markdown. Исходники передаются точным `code`, подписи — `label`. Для извлечения исполняемого кода свой сборщик читает файлы и формирует данные.
- design-patterns сохраняет guide, содержательную модель, навигацию, старый /web/, ключи patterns.* и миграцию editor/theme. Общий worker сохраняет префикс patterns: и scope.
- Sphinx сохраняет Markdown, формулы, literalinclude и выбор реализаций. Пакетные ресурсы готовятся в генерируемом doctreedir и подключаются через html_static_path до HTML-рендера: сохраняются штатные хеши CSS. Ключи algorithms.* сохранены.
- Удалены 53 пакетных дубликата у паттернов и 56 у алгоритмов после резервной копии и успешных overlay-сборок. Список: `/private/tmp/course-engine-extraction-baseline/removed-duplicates.json`.

## Дистрибутив

Wheel: `dist/course_engine-0.1.0-py3-none-any.whl`.
SHA-256: `042ae522a3c18168919170c083fdda4de2c844110063f18fef5aa6512f480095`.
Одинаковые байты находятся в vendor/ обоих курсов и зафиксированы в обоих uv.lock. Нет зависимости от ../course-engine. У алгоритмов зависимость находится только в группе docs.

`uv build` собрал sdist и wheel из него. `uv build --wheel --out-dir dist/direct` собрал wheel напрямую; cmp подтвердил их побайтовое равенство. Чистая установка wheel вне checkout и сборка минимального курса прошли, включая локальные импорты, CSS и шрифты. Sdist включает пример, тесты и средство проверки дистрибутива.

Команды проверки:

```sh
uv run --locked pytest -q
node --test tests/*.test.mjs
uv run --locked ruff check .
uv run --locked ruff format --check .
uv build
uv build --wheel --out-dir dist/direct
UV_OFFLINE=1 uv run --no-sync python tools/verify_distribution.py dist/course_engine-0.1.0-py3-none-any.whl
openspec validate --all --strict
```

Результат: 13 Python-проверок, 6 Node-проверок, Ruff и OpenSpec — успешно. Node проверяет изоляцию хранилищ, миграцию через adapter callback, точное копирование, один/два исходника, исходные строки без diff и изоляцию кешей по курсу/scope. Это не визуальная приёмка.

## Основание и восстановление

Резервная копия до изменений: `/private/tmp/course-engine-extraction-baseline/courses-before.tar.gz`.
Контрольные суммы материалов, исходные git status, удалённые дубликаты и оба набора HTML-хешей находятся рядом. Исходный HEAD паттернов: df5ef7e50e220cdfc1f960666c6c47e7153e1a32; алгоритмов: 9514098fe4577bb40a8616e574727abfb73e90e3. Большие рабочие изменения паттернов были сохранены; HEAD не использовался как источник актуального UI.

Откат интеграции: восстановить изменённые адаптеры, инструкции, зависимости и удалённые ресурсы из точной резервной копии, сохраняя остальные рабочие изменения. Для будущих выпусков менять версию wheel; не перезаписывать выпущенные байты под прежним именем.

Во время разработки изменение README draft-wheel изменило его hash. Обычный uv lock --refresh-package сохранил прежний hash и sync корректно отклонил файл. Запись локальной зависимости пересоздана через uv remove --no-sync и uv add --no-sync, после чего hash-проверка и обе независимые установки прошли. Все конечные копии имеют SHA-256, указанный выше. Сетевые ограничения sandbox обходились разрешёнными escalated-командами; последняя установка дистрибутива проверена офлайн по кешу.

## Ограничения и следующий шаг

`cua.getState()` вернул пустые browsers/apps. Не проверены реальные 320/768/1024/1440px, фокус/клавиатура, буфер браузера, физическая установка, холодная загрузка и офлайн-обновление в браузере. Узкие экраны и DOM-поведение не объявляются подтверждёнными по Node.

Полная strict-проверка OpenSpec алгоритмов: 18 passed, 7 failed. Те же 7 объектов не проходили strict до интеграции (проверено по сохранённому openspec: 17 passed, 7 failed): advanced-graph-algorithms, algorithm-course-content, divide-and-conquer-algorithms, documentation-site, linear-containers, sorting-algorithms и чужой readable-fibonacci-lesson. Причина — требования длиннее 500 символов. Их тексты не менялись. Собственный use-shared-course-engine валиден.

Все новые changes оставлены открытыми до приёмки; чужие changes не завершались. Следующий шаг — браузерная проверка двух локальных сайтов, затем отдельное решение по старым OpenSpec-предупреждениям. Публикация требует отдельного запроса.
