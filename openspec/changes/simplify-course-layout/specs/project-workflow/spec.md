## MODIFIED Requirements

### Requirement: Запуск через uv
Проект MUST содержать pyproject.toml, uv.lock, пакет в src и инфраструктурные проверки в tests. Python-примеры, тесты, сборка и локальный сервер MUST запускаться через uv с выбранным Python 3.15 или новее. Команды в учебных материалах MUST показывать запуск через uv. Проект MUST NOT требовать make или содержать Makefile. ZIP-комплекты MUST NOT создаваться; примеры запускаются из examples/ или после копирования кода.

#### Scenario: Запуск примера
- **WHEN** пользователь запускает указанную команду базового или расширенного примера
- **THEN** uv выбирает требуемый Python, и пример выполняется

#### Scenario: Проверка и просмотр курса
- **WHEN** пользователь запускает указанную uv-команду тестов, сборки или локального сервера
- **THEN** Python-команда выполняется без make

#### Scenario: Скачанный пример
- **WHEN** пользователь копирует файлы полного примера и выполняет указанную uv-команду
- **THEN** пример запускается без скачивания ZIP
