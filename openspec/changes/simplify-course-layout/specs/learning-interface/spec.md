## MODIFIED Requirements

### Requirement: Проверяемые примеры и совместимость входов
Все готовые примеры MUST быть исполняемыми и иметь проверки существенного поведения. Шаблон входа MUST находиться в web/index.html; собранный курс MUST открываться из корня .build/site и GitHub Pages, прежний /web/ MUST перенаправлять туда с сохранением раздела; отдельные страницы в lessons/ и reference/ MUST NOT публиковаться или генерироваться. При отключённом JavaScript входная страница MUST сообщать о необходимости его включить. Результаты исполнения и ограничения проверки MUST фиксироваться явно.

#### Scenario: Проверка курса
- **WHEN** запускаются проверки примеров и интерфейса
- **THEN** проверяется поведение готовых Python-тем и основные пользовательские переходы, а отчёт указывает фактически проверенную среду
