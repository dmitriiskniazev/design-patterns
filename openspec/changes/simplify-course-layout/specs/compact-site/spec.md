## ADDED Requirements

### Requirement: Компактное исходное дерево
Проект MUST хранить интерфейс и единый авторский файл web/lessons.json в web/. Отдельные assets/ и content/, ZIP-комплекты и отслеживаемые результаты сборки MUST отсутствовать. Исполняемый Python MUST оставаться в examples/.

#### Scenario: Изменение главы
- **WHEN** редактор меняет материал курса
- **THEN** он меняет web/lessons.json и Python-исходники без ручного редактирования производных данных

### Requirement: Изолированная сборка
Команда uv run build-course MUST собирать полный сайт только в .build/site, не изменяя исходное дерево. Публикация MUST содержать только необходимые браузеру ресурсы и совместимый переход со старого /web/. ZIP и отдельные копии Python MUST NOT публиковаться.

#### Scenario: Чистая сборка
- **WHEN** сборка выполнена из свежего checkout
- **THEN** все 25 тем доступны в собранном сайте, Git остаётся чистым и ZIP не созданы

#### Scenario: Прежняя ссылка
- **WHEN** открыта ссылка /web/#adapter/examples
- **THEN** открывается тот же раздел в корне сайта

#### Scenario: Офлайн после обновления
- **WHEN** установлена новая версия и отключена сеть
- **THEN** главы и полные исходники доступны, включая переход по прежней ссылке
