# Паттерны проектирования на Python

[Открыть курс](https://dmitriiskniazev.github.io/design-patterns/). **23 GoF-паттерна** и два дополнительных подхода: **Repository** и **Dependency Injection**. Python3.15+.

Большинство примеров максимально абстрактны: роли паттерна, нейтральные значения и направление вызовов. Abstract Factory использует согласованную пару чтения и записи JSON/YAML/TOML; бизнес-правила не добавляются. В большинстве глав две пары коротких фрагментов: основная операция и одно расширение. Варианты без паттерна и с паттерном дают одинаковый результат.

Два режима: **Разбор** и **Код**. Разбор идёт от задачи через простое решение к паттерну, расширению и цене. Короткие фрагменты показаны целиком; схема и определения раскрываются в «Связях участников». В режиме кода список обязанностей выбирает одну смысловую пару файлов **baseline / pattern**. Разные имена сопоставлены по роли, реальные пути видны над кодом. Колонки имеют общую вертикальную прокрутку и выровненные строки. На узком экране доступен переключатель стороны; общие файлы показаны один раз. Один селектор выбирает основной или расширенный пример. Простая функция может оказаться удобнее паттерна.

## Запуск

```sh
uv sync
uv run build-course
uv run test-course
uv run pytest
uv run python -m http.server 8000 --bind 127.0.0.1 --directory .build/site  # http://localhost:8000/
uv run --directory examples/strategy python -m pattern.main
uv run --directory examples/strategy python -m baseline.main
uv run test-course strategy
uv run pytest examples/strategy/test_example.py
```

Все команды выполняются из корня. Python выбирается через uv; другая версия задаётся `uv run --python 3.16 …`. `test-course` находит тесты всех примеров и запускает каждую папку отдельным процессом; аргумент выбирает одну тему. `pytest` без пути проверяет только `tests/`.

## Структура

- `web/index.html`, `web/lessons.json` — оболочка и главы.
- `web/src/` — адаптер курса: навигация, уроки, смысловые пары и совместимость настроек.
- `course-engine` — общие настройки, темы, шрифты с лицензиями и компоненты просмотра; сборка копирует их из установленного пакета в `.build/site`.
- `.build/site/` — готовый сайт; создаётся сборкой и не хранится в Git.
- `examples/strategy/` — конфигурации baseline, стратегии pattern, один набор тестов.
- `examples/abstract_factory/` — общий `formats/`, два клиента `baseline/` и `pattern/`, один набор тестов.
- `examples/<pattern>/{base,extended}/{without_pattern,with_pattern}/` — четыре автономных варианта темы; в каждом `main.py`, ролевые модули и `test_example.py`.
- `src/design_patterns/`, `tests/` — сборка и инфраструктурные проверки.
- `openspec/` — требования и история изменений.

Для остальных23 глав сначала выберите этап — `base` или `extended`, затем реализацию — `without_pattern` или `with_pattern`. Любую конечную папку можно скопировать и запустить отдельно: `uv run --no-project --python 3.15 main.py`; её тесты — `uv run --no-project --python 3.15 --with pytest python -m pytest`. Импортов из соседних вариантов нет. Одинаковые маленькие модули повторяются намеренно; базовая версия не содержит новые классы расширения заранее.

Strategy использует две конечные версии. В baseline конфигурации `Add(amount)`, `Multiply(factor)`, `Constant(value)` обрабатываются через `match`; в pattern они реализуют `Strategy.apply`. `Context.apply_all` обходит список и допускает замену текущей операции в обеих версиях. Основной вызов и добавление Constant объясняются по конечному коду. Тест проверяет также внешний алгоритм без наследования. Для копирования берите всю папку `strategy`, запуск из неё — `uv run --no-project --python 3.15 -m pattern.main`, тест — `uv run --no-project --python 3.15 --with pytest python -m pytest`.

Abstract Factory — первый пример новой структуры. Общие `interfaces.py`, `validation.py` и `formats/{json,yaml,toml}.py` используются клиентами `baseline/` и `pattern/`. Фабрики находятся в `pattern/factories.py`. Обе версии уже включают TOML; глава показывает его добавление без отдельных снимков `base/extended`. В полной реализации доступны две колонки без переключателя этапа. Второе направление расширения тоже реализовано: `Validator` проверяет входной текст и словарь строк; все фабрики имеют `create_validator`, оба клиента — `validate_and_read`. В главе три сравнения: исходная операция, TOML, Validator. Успешный текст разбирается дважды — при проверке и чтении; для прикладного кода часто проще объединить эти действия.

Из корня проекта:

```sh
uv run --directory examples/abstract_factory python -m baseline.main
uv run --directory examples/abstract_factory python -m pattern.main
uv run test-course abstract_factory
```

Для независимого запуска копируйте всю папку `abstract_factory`, затем из неё:

```sh
uv run --no-project --python 3.15 --with PyYAML==6.0.3 --with tomli-w==1.2.0 python -m pattern.main
uv run --no-project --python 3.15 --with PyYAML==6.0.3 --with tomli-w==1.2.0 --with pytest python -m pytest
```

Первый запуск uv может требовать сети для установки Python и зависимостей. Чтение уже сохранённого сайта работает отдельно от запуска примеров. Скачивание ZIP не требуется.

Переключатель **Изменения** подсвечивает различия выбранной пары baseline/pattern и включён по умолчанию. Кнопка копирования берёт полный исходный файл без номеров и заполнителей. Команды запуска и сведения о файлах находятся в «Действиях».

Каталог включает22 адаптации тем для всего интерфейса, в том числе One Light/Dark, GitHub Light/Dark, Dracula, Monokai и [Verdandi / Verdandi Alter](https://github.com/be5invis/vsc-theme-verdandi). Подсветка создаётся Pygments; это адаптации для курса, а не точная копия каждого редактора. Уведомление Verdandi MIT сохранено в CSS.

После изменения исходников: `uv run build-course`. Проверка требований: `openspec validate --all --strict`.

## GitHub Pages и iOS

`uv run build-course` собирает сайт в `.build/site`, не изменяя исходники. Одна сборка используется локально и на GitHub Pages. Старые ссылки `/web/#…` перенаправляются на тот же раздел. ZIP не создаются: полный код доступен для чтения и копирования на странице.

В репозитории GitHub выберите Settings → Pages → Source → GitHub Actions. Workflow публикует ветку main и допускает ручной запуск. Для репозитория design-patterns адрес имеет вид https://dmitriiskniazev.github.io/design-patterns/.

На iPhone/iPad откройте адрес в Safari → Поделиться → На экран «Домой» → Открывать как веб-приложение. Дождитесь надписи «Курс доступен офлайн». После этого локальные материалы и код доступны без сети; внешние источники требуют интернета. Система может очистить кеш при нехватке места — тогда снова откройте курс онлайн.

Место чтения сохраняется на устройстве; ссылка с явно указанным разделом имеет приоритет. Синхронизации между устройствами нет. Загруженное обновление применяется после закрытия всех окон курса и повторного открытия.

## Настройки интерфейса

Кнопка «Настройки» открывает боковую панель, на телефоне — полноэкранную. Изменения применяются сразу; доступны сохранение на устройстве, сброс раздела и общий сброс.

- **Темы:**22 готовых оформления страницы и кода, поиск, светлые/тёмные варианты, избранное, выбор по системе.
- **Типографика:**9 встроенных шрифтов, размер, насыщенность, межстрочный интервал, расстояние между символами, лигатуры и курсив.
- **Код:** номера строк, обычные/цветные направляющие, пробелы/табуляции и пробелы в конце строк, подсветка.
- **Чтение и сравнение:** перенос (при нём номера скрываются), ширина, diff по умолчанию и связанная горизонтальная прокрутка парных файлов.
- **Импорт VS Code:** выбор settings.json либо вставка JSONC. Комментарии, завершающие запятые и настройки [python] поддерживаются. Сначала показывается отчёт, изменения применяются отдельной кнопкой. Неизвестные темы/шрифты/параметры пропускаются. Распознанная тема явно включает подсветку синтаксиса; это указано в предпросмотре. Настройки остаются на устройстве; авторизация не требуется.

Гарнитуры: JetBrains Mono, Fira Code, Source Code Pro, IBM Plex Mono, Roboto Mono, Ubuntu Sans Mono, Geist Mono, Cascadia Code и Meslo Nerd Font (MesloLGM Nerd Font Mono). Все поставленные начертания проверены на русский алфавит, включая Ёё. Fira Code и Source Code Pro поставляются только прямыми начертаниями с полным русским набором; синтетический курсив отключён. У Meslo доступны обычное, жирное, курсивное и жирное курсивное начертания. Файлы WOFF2 занимают около6.8МБ; поставки/лицензии и источники находятся рядом с ними. После первой успешной офлайн-установки они доступны без сети.

Просмотр использует ES-модули: открывайте готовый сайт через HTTP-сервер или установленную офлайн-копию, не file://. Полные файлы и diff копируются из исходных данных; визуальные пробелы и отступы не добавляют символы в копию.

## Общий движок

Оформление поставляет [course-engine](https://github.com/dmitriiskniazev/course-engine).
Зависимость закреплена на коммите `9238e04d05dbf295635ede6888f09e4bc0706cc4` в `pyproject.toml` и `uv.lock`.
Курс устанавливается через `uv sync --locked`, сборка остаётся `uv run build-course`.
Для обновления проверьте новый коммит на обоих курсах и выполните:

```sh
uv add 'course-engine @ git+https://github.com/dmitriiskniazev/course-engine' --rev '<full-sha>'
uv sync --locked
uv run test-course
uv run build-course
```

Сохраните dependency/lock вместе с адаптером. Соседний checkout движка и локальный
wheel не требуются. Откат — возврат предыдущего SHA/lock и соответствующего адаптера.
